# Portfolio source

This is the cleaned version of the bundled portfolio. The visual content, wording, links, images, fonts, PDF, and CSS animations were preserved.

## Structure

- `index.html` — page content and semantic HTML structure
- `styles.css` — all styling and animations
- `assets/images/` — portfolio images
- `assets/fonts/` — locally bundled fonts
- `assets/resume/Isar_U.pdf` — resume download

No JavaScript is required for this version because the original JavaScript was export/editor runtime code. The resume link now points directly to the extracted PDF, and the exported custom image placeholders were converted to standard `<img>` elements.
